1. Baixe o projeto no github
https://github.com/igor-de-andrade/pokemon-api

2. Abre o projeto no visual studio code
code .

3. Instalação
npm install

4. Executar Api Rest
npm run start:rest

http://localhost:3000/api-docs/

npm run start:graphql
