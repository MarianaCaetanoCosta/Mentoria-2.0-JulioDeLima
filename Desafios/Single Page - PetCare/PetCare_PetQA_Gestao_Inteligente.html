Tutorial de utilização

Um guia rápido para navegar e usar os principais recursos do PetCare + PetQA.

1. Conheça o Menu principal

Use o menu lateral para abrir Visão geral, Tutores, Animais, Clínicas, Lembretes, Agendamentos, Financeiro, Relatórios, Backup e este Tutorial. Cada opção abre sua própria tela.

2. Cadastre os dados básicos

  1. Em Tutores, cadastre a pessoa responsável.
  2. Em Animais, cadastre o pet e associe-o ao tutor.
  3. Em Clínicas, cadastre o local de atendimento.
  4. Use as ações de cada tela para incluir, pesquisar, editar ou excluir registros. Vínculos existentes podem impedir exclusões para proteger os dados relacionados.

3. Organize lembretes e atendimentos

  1. Em Lembretes, associe um cuidado ao animal e informe a data; a clínica é opcional.
  2. Em Agendamentos, selecione animal, clínica, serviço, data e horário.
  3. Inicie o atendimento pela ação disponível no agendamento. A conclusão só fica disponível a partir do horário marcado; informe o valor combinado e a data de conclusão.
  4. Para desfazer uma conclusão, use Anular e informe o motivo. O registro permanece no histórico, mas deixa de compor os serviços concluídos e o saldo a receber. Se houver pagamentos, devolva os valores pelo meio de pagamento e registre o estorno integral de cada pagamento no Financeiro antes de anular; o registro do estorno no sistema não transfere dinheiro.
  5. Links de WhatsApp e e-mail abrem o aplicativo correspondente com uma mensagem preparada. Revise e envie por conta própria.

4. Consulte o financeiro e os relatórios

O Financeiro separa serviços concluídos, recebimentos líquidos de estornos e saldo a receber. Registre pagamentos pelo atendimento concluído; pagamentos parciais são aceitos até o limite do saldo. Para registrar um estorno, confirme que a devolução já foi feita fora do sistema e informe motivo, data e valor. Em Relatórios, selecione uma categoria ou Total; use Baixar PDF para gerar um arquivo ou Imprimir relatório para abrir a impressão do navegador.

5. Proteja seus dados

Os dados ficam no armazenamento local deste navegador e não são sincronizados com outros dispositivos. Abra Backup no Menu principal e exporte um JSON periodicamente. Restaurar um backup substitui os dados atuais e requer confirmação.
